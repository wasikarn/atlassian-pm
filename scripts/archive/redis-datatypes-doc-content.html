Relationship to BEP-3302 (Bentocache Migration)

ทั้ง 14 tickets ใช้ ioredis ตรง (specialized Redis commands) ไม่ใช่ Bentocache:

  • Bentocache = key-value cache abstraction (getOrSet, tags, grace period, stampede protection)
  • ioredis direct = specialized data structures (ZADD, HINCRBY, GEOADD, PFADD, SETBIT, etc.)
  • ทั้งสองอยู่ร่วมกันได้ — share Redis connection เดียวกัน, แบ่ง scope ชัดเจน

ดู parent guide section 9.3 สำหรับ scope แบ่งระหว่าง Bentocache กับ ioredis
